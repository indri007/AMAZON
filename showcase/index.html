Salin & jalankan perintah ini langsung di terminal Cloud Shell Anda

Di terminal Google Cloud Shell yang sedang aktif (g25067020011@cloudshell:~$), jalankan perintah berikut secara berurutan:
1. Cek & Pilih GCP Project Anda: Salin Perintah 
gcloud projects list
gcloud config set project [PROJECT_ID_ANDA]
2. Clone Repo AMAZON & Deploy Langsung: Salin Perintah 
git clone https://github.com/indri007/AMAZON.git
cd AMAZON
gcloud run deploy amazon-showcase \
  --source . \
  --region asia-southeast2 \
  --allow-unauthenticated \
  --port 8080
Setelah deployment selesai (~2 menit), Google Cloud Run akan memberikan URL publik HTTPS yang dapat langsung diakses dari browser maupun diintegrasikan ke IBM Bob / Streamlit!
